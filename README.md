# FolderGoblin

> 小妖精，专揪你硬盘里占地方的东西。

A fast, honest folder size analyzer for Windows. No install, no dependencies — double-click and go.

选一个文件夹，它把里面每个子文件夹、每个文件占多大，从大到小排给你看，还有一张"结构图"把整个目录画成色块，谁最占地方一眼看穿。

## 下载使用

1. 到 [Releases](../../releases) 页面下载最新的 `FolderGoblin.zip`
2. 解压，双击里面的 `FolderGoblin.exe`
3. 点"选择文件夹"，挑你要看的目录，等它扫完

不需要安装 Python，不需要装任何东西，Windows 双击就能跑。

> ⚠️ `FolderGoblin.exe` 和它旁边的 `_internal` 文件夹是**一整套**。
> 拷给别人时把整个 `FolderGoblin` 文件夹一起拷，只拷 exe 会打不开。

## 有什么功能

- **边扫边显示**，扫大目录不卡死，可以暂停 / 继续 / 停止
- **大小 + 占比**：每个文件夹 / 文件显示大小和占父目录的比例，支持按大小、名称排序
- **结构图**：方块图看谁占地方（面积 = 大小），思维导图看结构，都能钻进去逐层看
- **路径气泡**：鼠标停在任意一行，弹窗显示完整路径，层级再深也不迷路
- **按名字搜索**，只摆命中的行，再大的目录也不卡
- **文件类型统计**：每类文件的大小、个数、占比
- **不藏私**：`node_modules`、`.git`、缓存目录全部照算，跟资源管理器同一个口径；有没算进去的（符号链接、读不到的），右下角「未计入」面板会一条条列出来，绝不偷偷少算

## 为什么数字跟资源管理器对不上

资源管理器对同一个文件夹给你**两个**数字：

| 资源管理器写的 | 实际是什么 |
|---|---|
| **大小** | 所有文件自己有多大，加起来。**本工具算的是这个** |
| **占用空间** | 按硬盘最小块（一个块通常 4 KB）算的实际占用。**一定比「大小」大** —— 一个 1 字节的文件也要占掉一整块 |

所以拿本工具的数字去对**第一个**数字（大小），别对「占用空间」。

剩下可能对不上的，「未计入」面板会全部列出来：

- **符号链接 / 快捷方式** —— 不跟进去（跟进去可能绕圈），列出个数
- **读不到的文件/文件夹** —— 按原因分类列出，见下一节
- 都没有时，面板写「无 —— 所有文件都算进去了」，说明数字是完整的

## 读不到东西是怎么回事

| 面板上写的 | 实际意思 | 该干什么 |
|---|---|---|
| 拒绝访问 | 没权限。系统文件夹之类（`System Volume Information`、`$RECYCLE.BIN`） | 正常现象，忽略。真想看就用管理员身份运行 |
| 文件或目录损坏 | **你的盘/文件系统坏了**，这一块目录结构读不出来 | 见下面 |
| 数据校验错 | 磁盘有坏道 | 见下面 |
| 文件被占用 | 别的程序正开着它 | 关掉那个程序再扫 |
| 文件已不存在 | 扫描过程中被删了 | 忽略 |

**出现「文件或目录损坏」怎么办**

这说明不是本工具的问题 —— 是真的读不出来，你在资源管理器里点进去也会报错。

1. **先把还能读的东西拷到别的盘**（重要：修复过程有可能把坏目录里的数据清掉）
2. 再修：
   - 图形界面：**此电脑 → 右键那个盘 → 属性 → 工具 → 检查 → 修复驱动器**
   - 或者命令行（管理员身份）：`chkdsk G: /f`
3. 修完再扫一次

> 实测一台 U 盘：资源管理器显示已用 45.1 GB，本工具只算出 2.05 GB。
> 排查后发现 64 个文件夹报「文件或目录损坏」，剩下 43 GB 根本读不出来 —— 工具没算错，是盘坏了。

## 快不快

扫描再大的目录也不卡界面 —— 扫描只摆顶层，点开哪个文件夹才展开哪个，搜索也只处理命中的行。

实测（2 万条目目录）：

| | 传统全量列表 | FolderGoblin |
|---|---|---|
| 扫描完成 | 好几秒 | **0.2 秒** |
| 列表行数 | 20,441 行 | **21 行** |
| 拖动窗口最长卡顿 | 351 毫秒 | **23 毫秒** |
| 搜一次 | 卡死好几分钟 | **6 毫秒** |

数字一个不少 —— 总大小、文件数、文件类型统计，整个目录都算过了。

## 结构图

列表适合盯着一个文件夹看，不适合看全局。扫完点工具条上的 **"结构图"**，另开一扇全景图：

| 模式 | 看的是啥 |
|---|---|
| **方块图** | **谁占地方**。一块地方 = 一个文件夹，面积就是它的大小 |
| **思维导图** | **啥结构**。一层占一列、从里到外铺开，连线越粗 = 越占地方 |

| 想干什么 | 方块图 | 思维导图 |
|---|---|---|
| 看某一块是啥 | 鼠标停住 → 气泡写完整路径 + 多大 | 一样 |
| 钻进去看里面 | **点一下**那块 | **双击**那块 |
| 退回上一层 | **右键**，或点"返回上一层" | 点"返回上一层" |
| 移动画面 | 不用 | **中键或右键按住拖** |
| 放大缩小 | 不用 | **滚轮** |

两个旋钮随时调：**画到第 N 层**（1~8）、**小于 X% 的不画**。顶层每个分支一个色系，同一文件夹底下一眼分得出。

## 从源码运行 / 自己打包

需要 Python 3（只用标准库，无第三方依赖）：

```bash
# 跑测试
python -m unittest test_folder_goblin

# 直接运行
python folder_goblin.py

# 打包（--onedir 文件夹版，别用 --onefile，单文件版每次启动都要先解包，慢好几秒）
python -m PyInstaller --noconsole --onedir --name FolderGoblin --icon icon.ico --add-data "icon.ico;." --distpath . --workpath _build_tmp --noconfirm folder_goblin.py
```

> 注意：打包别加 `--specpath`，加了它 `--add-data` 的相对路径会找错地方。
